# Obstacle models: licenses

All models in this folder are by **Kenney** (www.kenney.nl), released under **CC0 1.0 Universal** (public domain dedication): https://creativecommons.org/publicdomain/zero/1.0/
Free for commercial use, no attribution required. Credit given voluntarily.

Files were taken from the GitHub mirror https://github.com/codelove-models/library (commit 306e4586663a74b64cdfabddc3ad737a73d693ed). Each GLB there carries `asset.copyright: "CC0 1.0 (public domain)"`; the mirror itself has no LICENSE file, so the license rests on the original Kenney kit pages listed below (each kit's License.txt reads "Creative Commons Zero, CC0").

Modifications: meshopt/WebP decoded, re-encoded as plain GLB (KHR_mesh_quantization, PNG textures <=512 px, no Draco/meshopt), rescaled, re-centred (base at y=0), and for `cone_line`, `fish_stall`, `veg_stall` and `cafe_table`, several kit pieces combined into one model. The colours of `trash_bin` and `cafe_table` were converted from sRGB to linear.
