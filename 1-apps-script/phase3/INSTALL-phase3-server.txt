HOW TO CHANGE THINGS FROM NOW ON (no code)
All in the Operations sheet. Changes show in the apps within 10 minutes.
To see them at once: in Apps Script pick cfgBump and press Run.
A row with a mistake is skipped (the old value stays). You see why in Executions > Logs.

 STAFF tab, one row per person
   ID            short, small letters, never change it (joe). It is their login.
   Name          full name shown in the apps
   Role          owner, assistant or trainer
   Trainer name  the name in the Trainer column of the session tabs (Joe). Empty for Romy.
   Email, Phone  only Majd sees them
   Max per hour  most clients this trainer takes in one hour across 1:1, 1:2, 1:3 (Joe: 3). Empty = no limit.
   Pay rule      fixed, tier or cut. Pay base, Pay cut, Fixed pay: the numbers of that rule.
   Active        N = can no longer sign in, old sessions still show their name
   Match text    a piece of the name to find in old session rows (mik finds Mike and Mikel)
   Trains in the gym  Y = shows in Book and Change trainer (Majd, Joe, Mikel, Melanie today)
   Arabic name   optional, used in the Arabic nutrition screens (Romy: رومي)
   New trainer: add a row, then run appSetup and appLinks to get their private link.

 PACKAGE TYPES tab, one row per package you sell
   Name          exactly as it should appear (keep the price in brackets like today)
   Passes, Price numbers
   Kind          1:1, 1:2, 1:3, Physio, Prehab, Osteo or Madero
   Valid days    days from the start (30 for monthly, 10 for singles)
   Valid months  use this instead of days (Madero 2, Prehab 3)
   Melanie       Y for "PT with Mel" packages (the client becomes Melanie's client)
   Trial, Free   Y for the free trial
   Active        N = can no longer be sold (old packages keep working)
   In client app Y = shown in "All Wellbe packages"
   The Package Type dropdown in PACKAGES belongs to the Operations sheet: add a new type there too.

 SETTINGS tab: Key, Value, Notes
   Change only the Value. Lists are written like ["Cash","Whish","Neo"] and numbers like 7.
   Examples: offers.m3Pct (3 month discount %), offers.m6Pct, offers.physioPrice, center.wa,
   hours.trial (trial hours), hours.blocked (holidays, like ["2026-12-25"]), windows.joinMinH,
   streak.days, game.cash.CENTS, insurance.rate.
