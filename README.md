# Wellbe Team app

Staff app for Wellbe Health Center. This repo holds only the screen (no client data).
All data stays in the Google Sheets and goes through the Wellbe W40 Backend (App.gs),
which only answers people who open their own private link.

Live: https://majd-wellbe.github.io/wellbe-staff-app/
New link for someone: run appResetKey('name') in the W40 Backend, send them the new link from the log.
